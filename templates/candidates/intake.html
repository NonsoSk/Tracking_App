How reading works

  • PDF and Word CVs are read directly.
  • Scanned PDFs and photos of hard-copy CVs are read by {% if AI_ENABLED %}AI (enabled){% else %}AI when an API key is configured, or by OCR if installed{% endif %}.
  • Duplicates are detected by email / phone — an existing profile is updated instead of duplicated.
  • CVs from the {{ COMPANY_SHORT_NAME }} careers mailbox can also be pulled in automatically (see README: fetch_cv_emails).
