How reading works

  • {% icon "file-text" "ico-16" %}PDF and Word CVs are read directly, including text boxes and tables: the name, contacts, sex, date of birth, state, LGA, education, NYSC, experience and skills.
  • {% icon "user-check" "ico-16" %}Every new profile is then checked against its CV by HR before it is matched or put forward.
  • {% icon "scan-text" "ico-16" %}Scanned PDFs and photos of paper CVs are read by {% if AI_ENABLED %}AI (switched on){% else %}AI once an API key is added, or by OCR where it is installed{% endif %}.
  • {% icon "copy" "ico-16" %}Duplicates are spotted by email or phone. The existing profile is updated instead.
  • {% icon "mail" "ico-16" %}CVs sent to the {{ COMPANY_SHORT_NAME }} careers mailbox can be pulled in automatically.
