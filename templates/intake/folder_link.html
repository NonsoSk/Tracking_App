Which kind of folder?

  1. {% icon "folder-open" "ico-16" %}A shared folder the portal can open (on the server, or a share IT has given it access to): type its full path. It shows as Linked once the portal's background worker has opened it.
  2. {% icon "link" "ico-16" %}A folder on someone's PC that the server cannot reach: install the connector on that PC (add a PC), then choose it here. The PC sends new files whenever it is on.
  3. {% icon "upload" "ico-16" %}Only need the files once? Upload them instead: an upload is a one-time copy, it does not watch the folder.
