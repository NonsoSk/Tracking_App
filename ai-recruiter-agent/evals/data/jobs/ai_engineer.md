# AI/ML Engineer, LLM Agents

We are building an AI recruiting agent that screens and interviews thousands of
experts a week. You will ship new agent capabilities to production.

## What you'll do
- Build and improve agent capabilities using modern LLMs.
- Develop backend services and APIs in Python.
- Evaluate model quality and improve it through experiments.

## Requirements
- 3+ years of professional Python software engineering.
- Experience building applications with LLMs and AI APIs (OpenAI, Anthropic or Bedrock).
- Hands-on experience with LangChain, LangGraph or LlamaIndex.
- Experience building REST APIs with FastAPI or Flask.
- Experience deploying services on AWS, GCP or Azure.

## Nice to have
- Experience with RAG pipelines and vector databases.
- Experience evaluating LLM output quality (evals, LLM-as-judge).
- Docker and CI/CD.

## Benefits
- Remote-first, flexible hours and a learning budget.
